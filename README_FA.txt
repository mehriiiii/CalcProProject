CalcPro - Android Studio Project

1) این پوشه را در Android Studio با Open باز کنید.
2) صبر کنید Gradle Sync کامل شود.
3) از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
4) فایل APK در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

Package: com.example.calcpro
Version: 1.0
